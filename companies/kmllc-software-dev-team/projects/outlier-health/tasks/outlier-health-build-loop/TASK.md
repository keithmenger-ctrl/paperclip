Run one cycle of the `builder-loop` skill for Outlier Health:

1. Pick up any review feedback from the Head of Software first.
2. Otherwise, take the next most valuable item from [Outlier Health](https://linear.app/kmllc/project/outlier-health-55386fdb8246).
3. Build it, verify it, and hand it to the Head of Software for review.

If there is nothing to build, or the work is blocked, leave a one-line status comment and exit.
